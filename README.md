# bitsgap-test
# Bitsgap QA Automation Test

## 📋 Описание
Проект включает в себя комплексный тест, который проверяет полный цикл торговой операции:

логин в систему

Настройка демо-режима

Выбор типа ордера (Limit)

Установка параметров ордера 

Размещение ордера через интерфейс

## 🛠 Технологии
Playwright - фреймворк для автоматизации тестирования

TypeScript - язык программирования

## ⚙️ Установка и настройка
Клонирование репозитория:

git clone https://github.com/Arinka75/bitsgap-test.git
cd bitsgap-test

Установка зависимостей

npm install

Установка Playwright браузеров

npx playwright install

## 🚀 Как запускать

Запуск всех тестов

npm test

Запуск в отладочном режиме

npx playwright test --debug

## 🔐 Авторизация в тестах: Storage State vs Login Flow
Выбранный подход: Storage State
В проекте используется подход с сохранением состояния аутентификации через storageState.json вместо выполнения полного flow логина в каждом тесте.

##📊 Сравнение подходов
Критерий	     Storage State	             Login Flow
Скорость	    ⚡️ Быстро (миллисекунды)	🐢 Медленно (секунды)
Надежность	    ✅ Высокая	               ❌ Зависит от UI/сети
Стабильность	✅ Стабильный	           ❌ Хрупкий (селекторы, UI)
Тестовые данные	🔄 Требует обновления	    ✅ Всегда актуальные
Сложность	    🟢 Просто	                🔴 Сложно
